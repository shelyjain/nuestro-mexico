# Nuestro México

Proyecto de la clase de Español sobre México — información general, reflexiones de la clase, La Bamba y el Día de los Muertos. Sitio de una sola página HTML (`index.html`), sin dependencias que instalar.

## Ver el sitio localmente

Solo abre `index.html` en cualquier navegador (doble clic, o arrástralo a una pestaña de Chrome/Safari/Firefox). No necesita servidor ni build step.

## Subirlo a GitHub

Desde esta carpeta:

```bash
git init
git add .
git commit -m "Sitio del proyecto de español sobre México"
git branch -M main
git remote add origin https://github.com/<tu-usuario>/<nombre-del-repo>.git
git push -u origin main
```

## Publicarlo con GitHub Pages (para tener un link en vivo)

1. En GitHub, entra al repo → **Settings** → **Pages**.
2. En "Build and deployment", elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, luego **Save**.
4. En un par de minutos tu sitio estará en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.
